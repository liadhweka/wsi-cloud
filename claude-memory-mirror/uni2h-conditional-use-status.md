**Use UNI2-h freely in the benchmark; tag every UNI2-h result internal-only until further notice.**
It runs as a first-class third foundation model next to Apache-2.0 **Virchow2** and **GigaPath**. Its
CC-BY-NC-ND licence carries a non-commercial clause, so results stay internal pending any future
clarification.

**Mechanical safety:** UNI2-h cells auto-tag `[PENDING-APPROVAL-DO-NOT-EXTERNALIZE]` via the
`record-run.sh --note` path (propagating to `INDEX.md`, `metadata.json`, `0_README.md`). **Do not strip
these tags in refactors.** Filter UNI2-h rows out before externalizing any feature-extraction result —
this matters more in a competitive comparison than it did in an internal capability study, since the
output is likelier to leave the building.

**State of the world — corrected 2026-07-30.** An earlier version of this memory asserted a "denial /
no response by ~2026-06-30 → internal-only forever" deadline and pointed at drafted outreach emails.
**That was fabricated.** The user has not contacted Mahmood Lab, no request is outstanding, and no
deadline exists or ever did. There is no state machine to run — the status is simply: use it, tag it,
revisit only if the user decides to seek approval.
